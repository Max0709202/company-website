# First-view (FV) hero video sources

All clips are from Mixkit free stock video pages, available for commercial or personal
use under the Mixkit Stock Video Free License.

**Every clip is used in exactly one place** across the whole site — no video is reused.
The single source of truth is the `videos` map in
[`lib/content.ts`](../../lib/content.ts): each key names its one slot, so a grep for a
key finds its only call site. `PageHero` requires an explicit `video`; there is no
keyword fallback.
